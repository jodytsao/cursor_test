# 🍽️ 餐飲管理系統後台儀表板

一個功能完整的餐飲管理系統後台分析儀表板，可以從 POS 資料進行深度分析，包括會員資料、桌邊點餐、線上點餐、外帶及訂位等資料，幫助餐廳經營者了解消費者習慣、菜品受歡迎程度、翻桌率及熱門時段，進而優化人力配置與食材備料。

## ✨ 主要功能

### 📊 資料分析功能
- **銷售趨勢分析** - 支援每日/每週/每月/每季/每年的銷售數據分析
- **訂單類型分布** - 分析桌邊點餐、線上點餐、外帶的比例
- **熱門時段分析** - 找出營業高峰與離峰時段
- **熱門菜品排行** - 顯示最受歡迎的菜品 Top 10
- **菜品分類銷售** - 依菜品類別分析銷售表現
- **翻桌率統計** - 分析各桌位的翻桌率與平均用餐時間
- **會員消費分析** - 追蹤會員消費習慣與排行
- **人力配置建議** - 根據訂單量建議尖峰與離峰時段人力配置
- **食材備料建議** - 依據熱門菜品提供每日備料建議

### 🎨 視覺化圖表
- 折線圖 - 銷售趨勢
- 圓餅圖 - 訂單類型與菜品分類
- 長條圖 - 熱門時段、熱門菜品
- 甜甜圈圖 - 資料分布

### 📱 響應式設計
- 支援桌面、平板、手機等各種裝置
- 美觀的使用者介面，漸層色彩設計

## 📦 安裝步驟

### 1. 安裝依賴套件
```bash
npm install
```

### 2. 建立示例資料
系統會自動生成過去 90 天的示例資料，包含：
- 15 位會員
- 35 項菜單
- 25 個桌位
- 約 3000+ 筆訂單
- 未來 7 天的訂位資料

```bash
npm run seed
```

或使用繁體中文指令：
```bash
npm run 建立資料
```

### 3. 啟動後端伺服器
```bash
npm run server
```

或使用繁體中文指令：
```bash
npm run 後端
```

伺服器預設運行於：`http://localhost:3001`

### 4. 開啟前端儀表板
在瀏覽器中開啟：
```
前端/儀表板.html
```

## 🔌 API 端點

所有 API 端點都支援 `開始日期` 和 `結束日期` 查詢參數。

### 總覽資料
```
GET /api/分析/總覽
```

### 銷售分析
```
GET /api/分析/銷售?分組方式=日
```
支援分組方式：`日`、`週`、`月`、`季`、`年`

### 熱門菜品
```
GET /api/分析/熱門菜品?數量限制=10
```

### 翻桌率分析

## 🗄️ 資料庫結構

### 會員資料表
- 會員編號、姓名、電話、電子郵件、點數、會員等級

### 菜單項目表
- 項目編號、菜名、分類、售價、成本、描述

### 桌位表
- 桌位編號、桌號、容納人數、狀態

### 訂單表
- 訂單編號、訂單號碼、會員編號、桌位編號、訂單類型、總金額、訂單狀態、建立時間、完成時間

### 訂單明細表
- 明細編號、訂單編號、項目編號、數量、單價、小計

### 訂位表
- 訂位編號、會員編號、顧客姓名、顧客電話、桌位編號、人數、訂位時間、訂位狀態

## 🔧 自訂設定

### 修改伺服器埠號
編輯 `後端/伺服器.js`：
```javascript
const 埠號 = process.env.PORT || 3001;
```

### 調整資料時間範圍
編輯 `前端/儀表板.html` 的下拉選單：
```html
<select id="時間範圍">
    <option value="7">最近 7 天</option>
    <option value="30">最近 30 天</option>
    <option value="90">最近 90 天</option>
</select>
```
